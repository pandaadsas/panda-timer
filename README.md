# 熊猫记替身 · 火影手游替身计时器

一个给《火影忍者手游》用的替身冷却计时器，两个版本：Windows（模拟器）和 Android（手机）。

**核心设计：纯手动触发，不读游戏画面、不检测豆、不注入进程、不模拟点击。**

按下按键或点一下悬浮窗就开始 15 秒倒数，剩下两秒数字变红，归零停在红色 `0.00`。

---

## 为什么不做自动检测

市面上同类工具普遍靠识别对手"豆"的数量变化来自动起计时。这条路有两个绕不过去的缺陷：

1. **分不清替身和主动消耗** —— 只看豆数 N→N−1，对手用技能主动消耗一颗豆也会被误判成替身。
2. **换分辨率、缩放、特效遮挡就失效** —— 固定像素采样对位置极其敏感。

手动触发牺牲了"自动"，换来的是 100% 的准确率：你觉得对面交替身了，按一下，倒计时就是准的。而且因为不读屏幕、不需要任何敏感权限，游戏侧完全感知不到它的存在。

## Windows 版（模拟器）

适用于 MuMu、雷电、夜神等任意模拟器，也可以在游戏窗口化时使用。

### 运行要求

- Windows 10 / 11
- 一个带 `tkinter` 的 Python 3（Windows 官方安装包默认自带）

只依赖标准库，不需要 `pip install` 任何东西。

### 启动

双击 `windows/启动计时器.bat`。

如果提示找不到 Python，把 `启动计时器.bat` 用文本编辑器打开，把其中的 `pythonw.exe` 路径改成你自己机器上的路径。

### 操作

| 操作 | 效果 |
|---|---|
| **左 Alt** | 立刻从 15.00 重新开始倒数 |
| 拖动窗口中间 | 移动位置，自动记住 |
| 拖动边缘或角落 | 缩放窗口，字号等比跟随 |
| 右键 | 打开设置菜单 |

右键菜单可调：倒计时秒数、热键（按任意键即绑定）、字号、面板透明度、恢复默认大小、退出。

### 注意

热键走的是键盘状态轮询，**不占用 Alt 键** —— `Alt+Tab`、`Alt+F4` 照常可用。代价是按 `Alt+Tab` 切窗口时也会触发一次计时。嫌烦就在右键菜单里换成 `F8` 或空格。

配置保存在 `%LOCALAPPDATA%` 下的独立文件中，不进仓库。

## Android 版（手机）

### 安装

从 [Releases](../../releases) 下载 `timer.apk` 安装。

- 需要 Android 7.0（API 24）以上
- 安装时系统会提示"未知来源"，需手动允许

### 权限说明

只有三个，且都是画悬浮窗所必需：

| 权限 | 用途 |
|---|---|
| `SYSTEM_ALERT_WINDOW` | 在其他应用上层绘制悬浮窗 |
| `FOREGROUND_SERVICE` | 保持计时器不被系统回收 |
| `POST_NOTIFICATIONS` | 通知栏常驻提示 |

**没有**录屏权限、**没有**无障碍服务、**没有**读取游戏内存、**没有**模拟点击。

无障碍服务是唯一的例外：部分自动化工具靠它精确捕获按键，但腾讯系游戏有能力检测无障碍环境并将其判定为模拟点击。本项目刻意不申请这个权限。

### 操作

| 操作 | 效果 |
|---|---|
| **点小方块** | 立刻重新开始倒数 |
| 拖动任一悬浮窗 | 移动，位置自动记住 |
| 长按任一悬浮窗 | 回到设置页 |
| 设置页「大小」滑块 | 两个窗等比缩放 |
| 设置页「面板透明度」滑块 | 30% ~ 100% |

### 国产系统必做设置

ColorOS / 鸿蒙 / MIUI 等系统的后台管理较激进，不设置的话游戏时悬浮窗可能被冻结或清除：

1. 设置 → 电池 → 应用耗电管理 → 本应用设为**允许后台运行**
2. 应用管理 → 自启动 → 允许本应用

### 自行编译

需要 JDK 11+、Android SDK（build-tools + platform 33 以上）、python3：

```bash
cd android
./build.sh
```

脚本会自动探测 SDK 路径和 build-tools 版本。首次运行会生成签名密钥 `keystore.jks`（密码可用环境变量 `KS_PASS` 指定，默认 `changeit`）。

`keystore.jks` 已在 `.gitignore` 中排除，**不要把它提交到仓库** —— 签名密钥泄露意味着任何人都能签出被系统认可的"官方更新包"。

## 已知限制

**Windows 版**
- 依赖 `tkinter`，未自带 Python 运行时的机器需先装 Python
- 窗口置顶由 Tk 实现，在少数全屏独占模式下可能被遮挡

**Android 版**
- 未在真机游戏内实测，仅在 Android 15 模拟器验证过悬浮窗、计时、拖动、缩放全流程
- 归零后停在 `0.00` 而不是自动回到 `?`，需要手动再按一次重新计时
